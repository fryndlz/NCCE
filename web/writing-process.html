01 — Writing pipeline (one path)

1Request

Exact prose form, subject, scope and intended audience.

2Evidence

Current campaign mechanics, authored canon and chronology.

3Voice

Faction → actual player gang → individual at the event's time.

4Literary craft

Form-specific target, appropriate register and illustrative examples.

5Draft

One source-bound piece; verify its quality and full Markdown length.

6Owner review

Saved text remains WRITING until explicit owner approval.

7Import

Reverify the exact draft, mark READY; relay imports unchanged.

03 — Form router: no universal length

Fighter biography

New drafts: target 1,900–2,000 characters including Markdown. Hard cap 2,300. Existing imported works are preserved.

Fighter memory

Experimental ~350–400 characters including Markdown; flexible where evidence requires.

Fighter reflection

Existing runtime: 60–130 words, grounded in cited memories.

Fighter Mind

Existing runtime: 12–40 words, immediate current concern.

Other prose forms

Use the specific live NCCE form contract; do not project biography limits onto reports, histories, events or ambient scenes.

Purposeful diegetic file codes, Imperial dates and seals may appear when the genre warrants them. Never duplicate NCCE app-generated IDs, dates or source revisions.

04 — Portable packet

Export from NCCE includes current versioned literary rules, voice registry, handoff instructions, sources and an illustrative excerpt index.

The separately maintained full offline packet contains the eight complete historical examples; the in-app ZIP intentionally exports only source-labelled excerpts and links.

05 — Owner-driven learning

1. You establish a durable, scoped correction.

2. An agent checks conflicts, evidence and the correct file.

3. It actually edits the policy, logs the decision and bumps the version.

4. Tests run; a new verified packet is built and retained for another chat.

This is an explicit file/repository operation, not automatic cross-chat memory.

06 — Verification boundaries

The policy version above comes from this running application. The ZIP includes the source files and a checksum manifest for verification.
