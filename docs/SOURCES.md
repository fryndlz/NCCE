## Research basis
The design is informed by:
- Generative Agents: memory stream, retrieval using recency/importance/relevance, reflection, planning.
- Reaction System Design: stims, personality/tendency, mood/reaction and propagation.
- Tynan Sylvester, Designing Games: mechanics as event generators; fiction gives mechanical events emotional meaning; emergent character arcs.

If local copies of those papers/books are added to `reference/`, treat them as design references, not game canon.
